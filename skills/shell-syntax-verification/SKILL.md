# Shell Syntax Verification

## Purpose
Produce deterministic syntax evidence for changed Bash and shell entrypoint
files. Mana executes `bash -n` through its fixed `bash_syntax` adapter; this
skill never authorizes a command parsed from Markdown or generated by a model.

## When To Use It
Use after shell files or hook entrypoints change, or invoke it explicitly in a
repository containing relevant changed shell files.

## Outputs
The canonical verification result records one check per file, effective argv,
parser result, bounded logs, provenance, duration, and observed effects.

## Decision Rules
- `passed`: Bash accepts the complete changed file.
- `failed`: Bash returns a parser failure.
- `inconclusive`: the file or required local tool is unavailable.
- `blocked`: a verification policy or bound prevents execution.

## Decision Boundary
A parser failure is evidence. This skill does not assign severity, recommend a
merge decision, or replace human review.

## Output Standard
Follow `docs/standards/agent-skill-output-standard.md`. Although the v1 adapter
makes no model call, any runner reading this normal skill must use compact
caveman reasoning mode and context budget discipline: preserve concise evidence
and artifact references, never raw logs or private chain-of-thought.
